What it does

Evidence in, clips out. Nothing else.

Transcript-first selection

Word-timed transcripts (local ASR with provenance) anchor every boundary to a real sentence. Proposals without transcript evidence are rejected, not guessed.

Multi-beat rendering

Clips render as structured beats — hook, body, payoff — reframed to 9:16 with captions overlaid exclusively by Gemmy Caption. Replaceable fills let you swap a beat without re-rendering the world.

Deterministic QA gates

Every render passes media checks (black frames, freezes, silence, A/V drift), caption QA, and visual QA. Outcomes are typed: publish-ready, review-required, or blocked — with reasons attached. The gates bite, including on our own showcase below.

Editing DNA transfer

Point at a reference video you admire. ClipFactory extracts its editorial behaviors, plans an edit of your raw footage in that style, validates the plan, then renders.

Gemmy Caption rails

One caption renderer, no fallbacks: HyperFrames rails (highlight, pill-karaoke, gradient-fill, editorial-emphasis, weight-shift…) overlaid by Gemmy. If Gemmy is missing, the render fails loudly instead of degrading silently.

Foundry plugin

Ships as a foundry-plugin.v1 capability pack: 8 commands (batch select/render/run, DNA extract/plan/render/assemble/variant) with schemas and typed results.

How it works

Two tracks, one principle: no evidence, no clip.

Track A · Batch clipping

  1. Inventory sources into a stable library manifest.
  2. Transcribe with word timings and provider provenance.
  3. Select a candidate bank — scored, reasoned, non-overlapping.
  4. Render multi-beat 9:16 clips, captions via Gemmy.
  5. Gate with media, caption, and visual QA.
  6. Review — you accept, hold, or reject. Nothing posts itself.

Track B · Editing DNA

  1. Extract behaviors from a reference video.
  2. Interpret them into a named, reusable style.
  3. Plan an edit of your raw footage in that style.
  4. Validate the plan against schemas and budgets.
  5. Render the styled edit, then assemble or variant the beats.

Ranking rule the engine enforces: QA status and evidence rank clips. Predicted views are never a ranking input.

Quickstart

On your machine in minutes.

Prerequisites

  • Python 3.12
  • ffmpeg + ffprobe on PATH
  • gemmy on PATH for ASR and caption overlays (typed error without it — never a silent fallback)
  • Optional: local LLM lane (Hermes proxy + CLIPFACTORY_LLM_ENDPOINT) for the DNA planner

Install & run

pip install -e .
python -m clipper_engine.cli batch-run --help
python -m clipper_engine.cli app        # desktop app, no quotas
python -m editing_dna --help            # style-transfer track

FAQ

Asked, answered.

Does ClipFactory post to TikTok for me?

No. It renders video files and evidence on your machine and stops. Uploading, posting, and submitting are human acts it cannot perform.

Does it need the cloud?

No. Selection, rendering, and QA run locally with FFmpeg, Gemmy (local GPU), and deterministic validators. The DNA planner can point at any OpenAI-compatible local lane; the showcase transfer above was planned by Grok through a local OAuth bridge — still no provider keys in the repo.

Are the videos above real?

Yes. Real engine outputs from a 27-minute source, with real transcripts, real caption rails, and real QA verdicts — failures included. Videos stream from public release assets; this page itself is static and collects nothing.

How is ranking kept honest?

Clips rank by QA status and evidenced score. Predicted views are never a ranking input, and financial summaries never treat raw views as cash.
